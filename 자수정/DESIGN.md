# 자수정 플랫폼 디자인

## 목적과 범위
단일 첨삭 도구를 홈 → 서비스 탐색 → 상세 안내 → 작업실로 확장한다. 크몽 공개 홈페이지의 검색, 카테고리, 서비스 탐색 흐름을 참고하되 자체 콘텐츠와 디자인을 사용한다. 실제 입점 전문가, 결제, 회원 시스템을 가장하지 않는다.

## 공통 체계
로고는 청록 A안의 보석/ㅈ SVG와 Pretendard 650 글자를 유지한다. 사용자 피드백에 따라 화면 색상은 로고 적용 전 기준으로 복원했다. `frontend/brand/brand.css`는 로고 배치만 담당하고 페이지 색상을 덮어쓰지 않는다. 심볼은 #148781이며 상표 검토 미완료인 임시 브랜드이다.

기존 `.calm-design/DESIGN.md`의 Pretendard, 종이색 #f3f1ec, 녹색 #285c48, 잉크색 #293c35를 계승한다. 브랜드는 프로젝트명 자수정으로 통일하고 기존 문장 다음은 작업실 이름으로 남긴다. 최대 1200px, 8px 중심 간격, 입력·버튼 최소 44px, 즉시 보이는 포커스. 의존성과 외부 이미지는 추가하지 않는다.

## 페이지
- `/`: 검색, 분야별 탐색, 서비스 카드, 이용 흐름, 작업실 안내.
- `/services`: 키워드/분야 GET 필터, 결과 수, 검색 결과 없음.
- `/services/<id>`: 대상, 제공 내용, 준비 자료, 제한, 작업실 진입.
- `/guide`: 실제 이용 흐름과 FAQ.
- `/workspace`: 기존 첨삭 도구. 선택 서비스는 검토 요청의 초깃값으로 전달한다. 기존 내용 자동 저장 없음.

## 표현과 구현
마케팅 홈에는 대비가 있는 녹색 배너와 편집 노트 그림을 사용한다. 서비스 카드는 자체 제작한 문서/질문 시각 요소를 담는다. 작업실은 기존 폼 UI를 유지한다. 모든 링크는 실제 경로로 연결한다. 목록/상세 페이지는 공통 HTML 진입점과 경로별 콘텐츠로 구성하고 서버는 허용된 경로만 제공한다. 새로고침/직접 링크 지원.

## 검증
기존 API 테스트 유지, 새 경로 및 없는 서비스 404, 검색 조합/비정상 입력, 실제 브라우저 홈 → 검색 → 상세 → 작업실 흐름, 모바일 가로 넘침 확인. 실거래·실제 AI 호출은 별도 구성 전까지 미검증.
