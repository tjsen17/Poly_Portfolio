# 파이썬과 MySQL로 만드는 가계부

## 현재 코드 실행 안내

현재 실행 파일은 `backend/main.py`입니다. 아래 1단계 설명은 초기 학습 기록이며, 현재 코드는 MySQL 데이터베이스와 테이블 생성 및 지출 저장까지 구현되어 있습니다. 실제 DB 연결 및 저장 동작은 이번 업로드 작업에서 검증하지 않았습니다.

로컬 MySQL 서버가 실행 중이어야 하며, 현재 연결 계정은 `root`, 데이터베이스는 `budget_db`입니다. 프로젝트 폴더에서 PowerShell로 실행합니다.

```powershell
python -m pip install mysql-connector-python
$env:BUDGET_DB_PASSWORD = Read-Host "로컬 MySQL 비밀번호" -MaskInput
python backend/main.py
```

`-MaskInput`은 PowerShell 7.1 이상에서 지원됩니다. 비밀번호는 현재 터미널의 환경변수로만 전달하며 코드나 Git에 저장하지 않습니다. 실행 후에는 `Remove-Item Env:BUDGET_DB_PASSWORD`로 지울 수 있습니다.

---

지출내역을 직접 입력하고 MySQL에 저장하는 개인 가계부를 조금씩 개발하는 프로젝트입니다.
작은 기능 하나를 직접 작성하고, 실행 결과와 코드의 의미를 이해한 뒤 다음 단계로 넘어갑니다.

## 목표

- 파이썬 프로그램에서 날짜, 사용처, 금액, 분류를 입력받기
- MySQL에 연결하고, DB와 지출 테이블이 없으면 생성하기
- 입력한 지출을 테이블에 한 행씩 저장하기
- 저장한 지출내역 조회하기

지출을 입력할 때마다 새 DB를 만드는 것이 아니라, 하나의 지출 테이블에 기록을 추가합니다.
CSV 업로드 방식은 사용하지 않습니다.

## 1단계: 사용처 입력과 출력

작성할 파일 이름은 `main.py`입니다. 프로젝트 폴더 바로 아래에 둡니다.

```text
가계부 만들기/
├── README.md
└── main.py
```

위 구조는 사용할 배치 예시입니다. 이 문서 작성 시 현재 폴더에서는 `main.py`가 확인되지 않았습니다.
다른 폴더에 저장했다면 실제 저장 위치를 확인합니다.

```python
place = input("어디에 사용했나요? ")
print("입력한 사용처:", place)
```

### 코드 이해하기

- `input(...)`: 질문을 표시하고 입력한 내용을 문자열로 돌려줍니다.
- `place = ...`: 입력받은 문자열을 `place` 변수에 저장합니다.
- `print(...)`: 안내 문구와 변수에 저장된 값을 출력합니다.
- `place`는 직접 정한 변수 이름입니다. 두 줄에서 모두 `store`로 바꾸면 같은 역할을 합니다.

### 실행하기

VS Code에서 `main.py`가 있는 폴더를 열고, 터미널에서 실행합니다.

```powershell
python main.py
```

사용자가 공유한 실행 결과:

```text
어디에 사용했나요? 편의점
입력한 사용처: 편의점
```

이 결과로 사용처 입력과 출력이 동작한 것을 확인했습니다.
현재 코드는 MySQL에 연결하거나 지출을 저장하지 않습니다.
입력한 값은 실행 중인 프로그램의 변수에만 담깁니다.

## 개발 방식

1. 작은 기능 하나를 직접 작성합니다.
2. 실행하고 결과를 확인합니다.
3. 코드가 왜 그렇게 동작하는지 이해합니다.
4. 확인한 변경을 커밋으로 남깁니다.
5. 다음 기능을 추가합니다.

첫 기능의 커밋 메시지 예시: `feat: 사용처 입력 및 출력 기능 추가`
